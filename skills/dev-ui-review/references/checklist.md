# UI 一致性审查清单

分两段使用：**A 段全量必查**，**B 段只在抽样点上查**（见 SKILL.md 步骤 1/3）。

## A 段 · blocker 级（全量必查）

### Token

- [ ] 无 hex 字面量；颜色全部来自 `--color-*`
- [ ] 无 px 字面量；间距来自 `--space-*`，圆角来自 `--radius-*`
- [ ] 字号/行高来自字阶 token，未自造字号

### 状态（以项目 `design/screens/*.md` 的矩阵为准）

- [ ] 矩阵里列出的状态都实现了（缺一个即 blocker）
- [ ] 空态有说明与下一步动作，不是白屏
- [ ] 加载是骨架或明确进度，不是裸转圈
- [ ] 错误可恢复：说明原因 + 重试入口

### 可访问性（硬指标）

- [ ] 正文 APCA Lc ≥ 60；实心按钮文字单独验证
- [ ] 图标按钮有 aria-label；表单有 label
- [ ] 颜色不是唯一信息载体（状态同时有文字/图标）

### 断点

- [ ] 至少一个移动断点（390）无布局塌陷
- [ ] 窄屏表格有明确降级（隐藏列或转卡片）

## B 段 · 抽样项（每个抽样点查）

### 结构与布局

- [ ] 该屏的区域划分与规格一致（页头 / 主区 / 侧栏 / 操作）
- [ ] 层级清楚：标题 → 区块 → 内容，没有同级抢焦点
- [ ] 栅格与最大宽度符合断点定义

### 交互细节

- [ ] 键盘可达：Tab 顺序合理，焦点可见
- [ ] 长文本与长数字不溢出、不截断关键信息
- [ ] 文案与路由、返回行为一致

### 交付

- [ ] 截图命名符合 `<screen>__<viewport>__<state>.png`
- [ ] 截图存放在 `.shots/`，未入库
