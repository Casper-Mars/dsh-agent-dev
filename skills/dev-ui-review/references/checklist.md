# UI 一致性审查清单

## 结构与布局
- [ ] 每屏的区域划分与规格一致（页头 / 主区 / 侧栏 / 操作）
- [ ] 层级清楚：标题 → 区块 → 内容，没有同级抢焦点
- [ ] 栅格与最大宽度符合断点定义

## Token
- [ ] 无 hex 字面量；颜色全部来自 `--color-*`
- [ ] 无 px 字面量；间距来自 `--space-*`，圆角来自 `--radius-*`
- [ ] 字号/行高来自字阶 token，未自造字号

## 状态
- [ ] default / empty / loading / error 齐全（列表页加 long-list）
- [ ] 空态有说明与下一步动作，不是白屏
- [ ] 加载是骨架或明确进度，不是裸转圈
- [ ] 错误可恢复：说明原因 + 重试入口

## 可访问性
- [ ] 键盘可达：Tab 顺序合理，焦点可见
- [ ] 正文 APCA Lc ≥ 60；实心按钮文字单独验证
- [ ] 图标按钮有 aria-label；表单有 label
- [ ] 颜色不是唯一信息载体（状态同时有文字/图标）

## 响应式
- [ ] 三个断点都验证过（1440 / 1024 / 390）
- [ ] 表格在窄屏有明确降级（隐藏列或转卡片）
- [ ] 长文本与长数字不溢出、不截断关键信息

## 交付
- [ ] 截图命名符合 `<screen>__<viewport>__<theme>__<state>.png`
- [ ] `check.mjs` 通过
