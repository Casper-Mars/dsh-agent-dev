# 开发任务计划验收条件

逐项验；不通过回到工作流程第 2–5 步对应项。

| # | 条件 | 通过线 |
|---|---|---|
| 1 | 任务粒度 | 每个任务一个负责人、一个可独立验收结果；不按文件或行数切 |
| 2 | 责任 | 每个任务恰好一个负责人；没有共同负责人 |
| 3 | 依赖 | DAG 无环；每个依赖写前置任务编号与方向 |
| 4 | 并行 | 同层任务不写同一文件，不争同一接口的归属 |
| 5 | 关键路径 | 标出关键路径，关键路径有可见缓冲 |
| 6 | 里程碑 | 每个里程碑有可检查结果，不只写日期 |
| 7 | 任务级验收 | 每条验收是可观察结果或命令，不看代码也能验 |
| 8 | 范围 | 覆盖 PRD / 方案范围；未覆盖项列出并说明；不含编码操作细节 |

## 返工记录

```text
[返工] 条件 <n> / 任务 <id>：<没过的证据>。
改法：<具体改什么>。
复核：<看哪个交付物或跑哪条检查>。
```

一轮只改一类问题；改完立刻重跑该项。同一项连续两轮不过，先检查验收条件本身是否写错。
